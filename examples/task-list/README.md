# 我的任务清单（原生 HTML / CSS / JavaScript）

一个零依赖的个人任务清单小项目：新增任务、勾选完成 / 取消完成、按「全部 / 待办 / 已完成」筛选，
数据通过 `localStorage` 保存在本机浏览器，**刷新页面数据不丢失**。

## 文件结构

```
.
├── index.html   # 页面结构
├── styles.css   # 样式（含深色模式自适应）
├── app.js       # 全部逻辑：数据层 + 操作层 + 视图层
├── tests/
│   ├── dom-check.mjs      # 零依赖 DOM 功能检查
│   └── mutation-check.mjs # 变异测试，验证检查脚本能发现回归
└── README.md
```

## 运行方法

不需要安装依赖、不需要构建，二选一：

**方式一：直接双击打开（最简单）**

在文件管理器中双击 `index.html`，或：

```bash
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

> 注意：部分浏览器（尤其 Safari、以及 Chrome 的某些隐私设置）对 `file://` 协议下的
> `localStorage` 有限制，可能无法保存数据。若发现刷新后数据丢失，请改用方式二。

**方式二：启动本地静态服务器（推荐，兼容性最好）**

在项目目录执行任意一条命令，然后浏览器访问 <http://localhost:8000/>：

```bash
python3 -m http.server 8000
# 或
npx serve .
```

## 功能说明

| 功能 | 操作方式 |
| --- | --- |
| 新增任务 | 输入框输入后按回车，或点击「添加」；内容为空会提示且不添加 |
| 完成 / 取消完成 | 点击任务前的复选框（可反复切换） |
| 筛选 | 点击「全部 / 待办 / 已完成」按钮 |
| 删除单条 | 鼠标悬停在任务上，点击「删除」 |
| 清除已完成 | 点击工具栏右侧「清除已完成」 |
| 数据持久化 | 每次改动立即写入 `localStorage`（键名 `personal-task-list.v1`） |

细节：

- 任务文本用 `textContent` 渲染，输入 HTML 标签也只会当普通文本显示，不存在 XSS 风险。
- 读取本地数据时会做校验与清洗，遇到损坏的 JSON 或非法字段会自动忽略，不会白屏。
- 隐私模式下 `localStorage` 不可用时，功能仍可用，只是数据不会保留（控制台会有警告）。
- 筛选状态不持久化：刷新后回到「全部」，任务与完成状态则完整保留。

## 自动化检查（可选）

项目自带一个零依赖的 DOM 功能检查脚本，覆盖新增、切换完成、筛选、刷新后持久化、删除、
空输入校验、XSS 防护、异常本地数据和 `localStorage` 不可用时的降级：

```bash
node tests/dom-check.mjs
```

输出每个断言的通过情况与最终结果（全部通过时退出码为 0）。检查脚本在 Node.js 中加载
真实的 `index.html` 和 `app.js`，用最小 DOM / `localStorage` 适配层驱动页面逻辑，因此无需
安装依赖或启动服务器；它不能替代真实浏览器的布局和兼容性验收。

要验证检查脚本能捕获回归，可运行变异测试：

```bash
node tests/mutation-check.mjs
```

## 手动验收清单

1. 添加「买牛奶」「写周报」「健身」三条任务 → 列表出现 3 条，计数显示「共 3 项 · 待办 3 项 · 已完成 0 项」。
2. 勾选「写周报」→ 文字出现删除线，计数变为「待办 2 项 · 已完成 1 项」。
3. 点击「已完成」→ 只显示「写周报」；点击「待办」→ 只显示另外两条；点击「全部」→ 恢复 3 条。
4. 按 F5 刷新 → 3 条任务与完成状态保持不变（筛选回到「全部」）。
5. 点击某条的「删除」→ 该条消失且刷新后不再出现。
6. 输入框留空点击「添加」→ 出现「任务内容不能为空。」提示，列表不新增。
